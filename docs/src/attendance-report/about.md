# Attendance Report

Generate attendance reports that include each employee’s photo and GPS location for every activity (check-in, check-out, break-start, break-end), enabling administrators to verify attendance records when needed.

| Feature | Description |
| ------- | ----------- |
| [Read](/attendance-report/read/) | Retrieves the work hour report, including recorded attendance times and calculated working hours. |
| [Export](/attendance-report/export/) | Exports the work hour report for external use or record-keeping. |
