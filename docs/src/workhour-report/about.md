# Workhour Report

Generate workhour reports showing each employee’s total working hours, break durations and net working time.

| Feature | Description |
| ------- | ----------- |
| [Read](/workhour-report/read/) | Retrieves the work hour report, including recorded attendance times and calculated working hours. |
| [Export](/workhour-report/export/) | Exports the work hour report for external use or record-keeping. |
