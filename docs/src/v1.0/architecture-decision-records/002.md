# ADR#002

## Topic

Choose naming options for break from work for any reason

## Problem

There are currently two naming options for break actions:

- `step-in` and `step-out`
- `break-start` and `break-end`

The term step-out may be confused with check-out, as both can imply that the user is leaving work. This could lead to user mistakes when performing attendance actions.

![alt text](https://absensi-docs.r2.lab.biz.id/attendances/attendance-workflow.webp){.landscape-img}

## Decision

Use `break-start` and `break-end` as the standard names for break actions.

## Reasoning

Break activities are distinct from checking in and checking out. Using break-start and break-end makes the purpose of each action clearer and reduces the risk of confusion with other attendance actions.
