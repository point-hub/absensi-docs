# My Account

The My Account menu allows users to manage and update their personal account information securely. It provides a central place for users to maintain their profile details and ensure their login credentials are up to date.

## Features

| Feature | Description |
| ------- | ----------- |
| [Update Username](/my-account/update-username/)       | Allows users to change their display username.                                               |
| [Update Email](/my-account/update-email/)             | Allows users to update their email address.                                                  |
| [Update Password](/my-account/update-password/)       | Enables users to change their account password.                                              |
| [Update Profile](/my-account/update-profile/)       | Enables users to change their name and profile picture.                                              |
