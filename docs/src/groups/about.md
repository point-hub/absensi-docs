# About Group

Group management features for organizing users.

## Features

| Feature | Description |
| ------- | ----------- |
| [Create](/groups/create/) | Creates a new group. |
| [List](/groups/list/) | Retrieves the list of groups available to the user. |
| [Read](/groups/read/) | Retrieves the details of a specific group. |
| [Update](/groups/update/) | Updates the details of an existing group. |
| [Delete](/groups/delete/) | Deletes an existing group. |
| [Invite User](/groups/invite-user/) | Invites a user to join a group using their email address. |
| [Accept Invitation](/groups/accept-invitation/) | Accepts an invitation to join a group. |
| [Reject Invitation](/groups/reject-invitation/) | Rejects an invitation to join a group. |
| [Remove User](/groups/remove-user/) | Removes a user from a group. |
